Hands-on Python exercises for LLM APIs, Spark log extraction, Pydantic validation, token usage analysis, and evaluation. Its README documents **50 labeled Spark log cases** and **six passing local regression tests**. Full model accuracy benchmarking remains future work.

A FastAPI service for incident analysis and severity classification, with structured guidance, SQLite history, log upload, and critical alert handling. The repository documents its API endpoints and local setup.
